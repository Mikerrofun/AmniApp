# AmniApp — Vision

> Универсальный клиент для общения с любыми ИИ-моделями: подключаешь свои API-ключи, получаешь чат с историей.

## Стек (уже задан проектом)

- **React Native + Expo (expo-router)**, NativeWind (Tailwind), TypeScript
- **Zustand** — состояние, **Zod** — валидация
- **expo-secure-store** — хранение API-ключей (секреты)
- **expo-sqlite** — история чатов и шаблоны (гибридное хранение: секреты в SecureStore, остальное в SQLite; слой абстракции над данными, чтобы потом можно было перенести на сервер/БД)

## Ядро идеи

Пользователь вставляет API-ключ любого ИИ-провайдера → создаёт «шаблон» (подключение к модели) → общается в чате. Приложение не привязано к конкретному провайдеру: в v1 поддерживаем OpenAI-совместимые API (OpenAI, OpenRouter, DeepSeek, Groq, Ollama и т.п. — один адаптер, отличается только base URL + ключ), архитектура оставляет место для отдельных адаптеров (Anthropic, Gemini) позже.

## Структура приложения

Нижний switcher из 3 вкладок + кнопка настроек приложения сверху.

### Вкладка 1 — Чат (основная)

- Основной чат с выбранной моделью (стриминг ответов).
- Внизу — выбор шаблона (подключённые модели; один ключ может быть в нескольких шаблонах или у каждого свой ключ).
- Слева (drawer) — история чатов: список, переименование, удаление, продолжение.
- Один ключ может использоваться несколькими шаблонами/провайдерами.

### Вкладка 2 — Шаблоны (самая важная и сложная)

- Список шаблонов с управлением: создать, редактировать, удалить, включить/выключить.
- Шаблон = провайдер (base URL) + ключ + выбранная модель + параметры (имя, системный промпт, температура и т.п.).
- Добавление: вставляешь ключ → предлагается **FastCheck** → выбор модели из полученного списка → сохранение шаблона.
- Шаблоны автоматически появляются в выборе моделей на вкладке чата.

### Вкладка 3 — FastCheck

- Принимает ключ (+ base URL) и прогоняет тестовые запросы:
  1. Ключ валиден (простой запрос).
  2. Список доступных моделей по ключу.
  3. Стриминг работает (тестовое сообщение со стримингом).
- Показывает отчёт по каждой проверке. Используется и как отдельная вкладка, и внутри добавления шаблона.

### Настройки приложения (кнопка сверху)

- Тема, шрифт.
- Расширенные настройки (по мере надобности).
- «Об авторе».

## Этапы реализации (черновой план)

1. **Скелет**: expo-router вкладки, навигация, пустые экраны, настройки темы.
2. **Провайдер-слой**: адаптер OpenAI-совместимых API (обычный + стриминг), zod-схемы конфига шаблона.
3. **FastCheck**: три проверки, UI отчёта.
4. **Шаблоны**: CRUD, SecureStore для ключей, SQLite для метаданных, появление в выборе чата.
5. **Чат**: экран чата, стриминг, выбор шаблона.
6. **История**: SQLite-схема чатов/сообщений, drawer с историей.
7. **Полировка**: настройки шрифта/темы, «об авторе».
