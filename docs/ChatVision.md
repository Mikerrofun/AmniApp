# Техническое задание: Вкладка "Чат"

## Обзор

Основная вкладка приложения для общения с AI-агентами. Пользователь может создавать несколько чатов, переключаться между ними, выбирать разные модели (шаблоны) для общения.

---

## Структура UI

### 1. Основной экран чата

```
┌─────────────────────────────────┐
│  [☰] Chat Name      [⚙️]        │ ← Хедер
├─────────────────────────────────┤
│                                 │
│  [Сообщения чата]               │
│                                 │
│  User: Привет                   │
│  AI: Здравствуйте!              │
│                                 │
│                                 │
│                                 │
├─────────────────────────────────┤
│ [Поле ввода]            [↗️]    │ ← Внизу
│ Выбрать шаблон ▼                │
└─────────────────────────────────┘
```

#### 1.1 Хедер
- **Левая часть**: Иконка бургер-меню (☰) для открытия Drawer с историей чатов
- **Центр**: Название текущего чата (генерируется автоматически встроенным агентом)
- **Правая часть**: Кнопка настроек приложения (⚙️)

#### 1.2 Область сообщений
- **Позиция**: Центр экрана, занимает основное пространство
- **Скролл**: Автоскролл к последнему сообщению при получении нового
- **Формат сообщений**:
  - Сообщения пользователя — справа, светлый фон
  - Сообщения AI — слева, контрастный фон
  - Поддержка стриминга: сообщение AI появляется постепенно
  - Markdown-форматирование в сообщениях AI (опционально)

#### 1.3 Блок ввода (внизу экрана)
- **Позиция**: Зафиксирован внизу экрана (sticky footer)
- **Состав**:
  1. **Поле ввода текста** (multiline textarea)
     - Placeholder: "Напишите сообщение..."
     - Автоувеличение высоты при вводе (до 4-5 строк)
  2. **Кнопка отправки** (справа от поля ввода)
     - Иконка: стрелка вверх-вправо (↗️) или отправка
     - Активна только когда есть текст
  3. **Селектор шаблона** (под полем ввода или выпадающий список)
     - При клике открывается список доступных шаблонов
     - Показывает текущий выбранный шаблон
     - Иконка стрелочка вниз (▼) для индикации

### 2. Drawer (боковая панель истории чатов)

Открывается при клике на иконку бургер-меню (☰).

```
┌────────────────────────┐
│ [🔍]  [⋮] Sort         │ ← Поиск и сортировка
├────────────────────────┤
│                        │
│ ▼ Новые                │
│   💬 Chat 1            │
│   💬 Chat 2            │
│                        │
│ ▼ На этой неделе       │
│   💬 Chat 3            │
│   💬 Chat 4            │
│                        │
│ ▼ Этот месяц           │
│   💬 Chat 5            │
│                        │
│ ▼ Старше месяца        │
│   💬 Chat 6            │
│                        │
└────────────────────────┘
```

#### 2.1 Шапка Drawer
- **Поисковое поле**:
  - Иконка лупы слева
  - Placeholder: "Поиск по чатам..."
  - **Динамический поиск**: фильтрация происходит при вводе (debounce 300ms)
  - Поиск по:
    - Названию чата
    - Ключевым словам из сообщений
    - (Опционально v2) Семантический поиск по контексту чатов

- **Кнопка сортировки** (иконка слева от поискового поля):
  - 3 режима (при клике переключается по кругу):
    1. **По дате (новые сверху)** — иконка ↓
    2. **По дате (обычное)** — иконка ↕️
    3. **По дате (старые сверху)** — иконка ↑
  - Иконка меняется визуально при переключении

#### 2.2 Список чатов

**Группировка по датам** (категории):
- **Новые** — чаты за последние 24 часа
- **На этой неделе** — чаты за последние 7 дней
- **Этот месяц** — чаты за последние 30 дней
- **Старше месяца** — все остальные

**Элемент чата**:
- **Иконка**: 💬 (или иконка модели, если есть)
- **Название чата**: автоматически сгенерированное встроенным агентом (краткое, 3-5 слов)
- **При наведении** (или долгом нажатии на мобильном): появляются три точки (⋮)
- **Клик на три точки**: открывается контекстное меню

**Контекстное меню чата** (мини-модалка):
- Позиция: рядом с тремя точками (от них начинается)
- Опции:
  1. **📌 Pin/Unpin** — закрепить чат вверху списка
  2. **✏️ Rename** — переименовать чат (открывает инлайн-редактор названия)
  3. **🗑️ Delete** — удалить чат (с подтверждением)

#### 2.3 Состояния Drawer
- **Пустое состояние** (нет чатов):
  - Показывать заглушку: "Начните новый чат"
  - Кнопка "Создать чат"
- **Поиск не дал результатов**:
  - Заглушка: "Ничего не найдено"

## Функциональные требования

### 3.1 Создание нового чата
- **Триггер**: при первом сообщении пользователя создается новый чат
- **Автоназвание**: встроенный агент анализирует первое сообщение и генерирует краткое название (асинхронно, после отправки)
- **Шаблон по умолчанию**: используется последний выбранный или первый доступный

### 3.2 Переключение между чатами
- **Клик на чат в Drawer**:
  - Загрузка истории сообщений из хранилища (SQLite или сервер)
  - Отображение истории в основной области
  - Drawer автоматически закрывается (на мобильных)
  - Обновление названия в хедере

### 3.3 Отправка сообщений
- **Триггер**: клик на кнопку отправки или Enter (Shift+Enter для новой строки)
- **Валидация**: нельзя отправить пустое сообщение
- **Процесс**:
  1. Добавить сообщение пользователя в UI и хранилище
  2. Отправить запрос к выбранному шаблону (модели)
  3. Получить ответ со стримингом
  4. Отображать ответ постепенно (streaming)
  5. Сохранить ответ в хранилище

### 3.4 Выбор шаблона (модели)
- **Открытие селектора**: клик на "Выбрать шаблон ▼"
- **Список**: показывает все активные шаблоны из вкладки "Шаблоны"
- **Формат элемента**:
  - Название шаблона
  - Провайдер (OpenAI, DeepSeek, Ollama и т.п.)
  - Модель (gpt-4, deepseek-chat и т.п.)
- **Выбор**: клик на шаблон → закрытие селектора → обновление текущего шаблона
- **Сохранение**: запоминать выбранный шаблон для каждого чата

### 3.5 Поиск по чатам
- **Динамический поиск**: фильтрация при вводе (debounce 300ms)
- **Критерии поиска**:
  - Название чата (полнотекстовый поиск)
  - Ключевые слова из сообщений чата
  - (v2) Семантический поиск по эмбеддингам
- **Результаты**: показывать только подходящие чаты (остальные скрыты)
- **Подсветка**: выделять найденные совпадения в названиях

### 3.6 Сортировка чатов
- **3 режима**:
  1. По дате (новые сверху) — default
  2. По дате (обычное) — хронологический порядок
  3. По дате (старые сверху)
- **Сохранение**: запоминать выбранную сортировку в настройках

### 3.7 Управление чатом
- **Pin (закрепление)**:
  - Закрепленные чаты всегда сверху (отдельная группа или маркер)
  - Сохраняется в БД
- **Rename (переименование)**:
  - Открывает инлайн-редактор прямо в списке
  - Сохранение: Enter или клик вне поля
  - Отмена: Escape
- **Delete (удаление)**:
  - Подтверждение через Alert: "Удалить чат? История будет потеряна"
  - Кнопки: "Отмена" | "Удалить"
  - Удаление из БД (мягкое удаление или жесткое — решить позже)

### 3.8 Streaming ответов
- **Реализация**: Server-Sent Events (SSE) или аналог
- **UI**: символы появляются постепенно, курсор мигает в конце
- **Прерывание**: кнопка "Остановить генерацию" (опционально)

## Хранение данных

### 4.1 Хранилище
**Варианты** (решить до реализации):
1. **Локальное (SQLite + SecureStore)**:
   - Чаты и сообщения → SQLite
   - API-ключи → SecureStore
   - Плюсы: работает оффлайн, приватность
   - Минусы: нет синхронизации между устройствами

2. **Серверное хранилище**:
   - Все данные на сервере пользователя
   - Плюсы: синхронизация, бэкапы
   - Минусы: требует сервер, зависимость от сети

3. **Гибридное** (рекомендуется):
   - Локальный кэш (SQLite) + синхронизация с сервером
   - Работает оффлайн, синхронизируется при подключении

### 4.2 Схема данных (SQLite)

```sql
-- Таблица чатов
CREATE TABLE chats (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  template_id TEXT, -- ID выбранного шаблона
  is_pinned INTEGER DEFAULT 0,
  is_deleted INTEGER DEFAULT 0
);

-- Таблица сообщений
CREATE TABLE messages (
  id TEXT PRIMARY KEY,
  chat_id TEXT NOT NULL,
  role TEXT NOT NULL, -- 'user' | 'assistant' | 'system'
  content TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (chat_id) REFERENCES chats(id) ON DELETE CASCADE
);

-- Индексы
CREATE INDEX idx_chats_updated ON chats(updated_at DESC);
CREATE INDEX idx_chats_pinned ON chats(is_pinned, updated_at DESC);
CREATE INDEX idx_messages_chat ON messages(chat_id, created_at);
```

## UI/UX детали

### 5.1 Анимации
- **Drawer**: плавное выдвижение слева (slide-in)
- **Переключение чата**: fade-in для новой истории сообщений
- **Новое сообщение**: плавное появление снизу
- **Streaming**: печатающий эффект (typewriter)

### 5.2 Адаптивность
- **Мобильные**: Drawer открывается поверх экрана (overlay)
- **Планшеты**: Drawer может быть постоянно видимым (split-view)

### 5.3 Состояния загрузки
- **Загрузка истории чата**: скелетон сообщений
- **Ожидание ответа AI**: индикатор "печатает..." или spinner
- **Отправка сообщения**: дизейбл кнопки отправки, spinner

### 5.4 Ошибки
- **Ошибка отправки**: показать toast с ошибкой, предложить повторить
- **Ошибка загрузки чата**: показать заглушку "Не удалось загрузить чат"
- **Нет доступных шаблонов**: заблокировать отправку, показать подсказку "Добавьте шаблон"

- Получение списка активных шаблонов для селектора
- Автообновление при изменении шаблонов

### 6.3 AI Provider Layer
- Использование единого адаптера для всех OpenAI-совместимых API
- Поддержка streaming responses
- Обработка ошибок API (rate limit, invalid key, network)
